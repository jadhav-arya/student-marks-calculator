
# Student Marks Calculator

## About the Project
Student Marks Calculator is a beginner-friendly Python project that calculates a student's total marks, percentage, and final result.

## Features
- Accepts student name
- Takes marks in five subjects
- Calculates total marks out of 500
- Calculates percentage
- Displays Pass or Fail result

## Technologies Used
- Python

## How It Works
The program accepts marks in English, Maths, Python, Science, and C++.
It calculates the total marks and percentage.
If the student scores at least 35 marks in every subject, the result is PASS. Otherwise, the result is FAIL.

## Learning Outcomes
- Python input and output
- Variables and data types
- Arithmetic operations
- If-else conditions
